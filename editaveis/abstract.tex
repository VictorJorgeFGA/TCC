\begin{resumo}[Abstract]
  \begin{otherlanguage*}{english}
    Modern web applications are generally divided into three main parts: back-end, front-end, and database. Frameworks based on design patterns such as Model View Controller (MVC) can experience scalability and performance issues, especially regarding intensive database usage and I/O bottlenecks for view rendering. A real case, the Brasil Participativo platform, reached a relatively high number of users (one million and four hundred thousand), which revealed several weaknesses and bottlenecks in the developed architecture and in the approach adopted for the development of the Decidim gem, built on top of the Ruby on Rails framework.

    This work aims to describe the development journey of improvements in one of the platform's features from a performance optimization perspective. To that end, research will be conducted on best development practices using the Ruby on Rails framework, and strategies for utilizing its resources with a focus on performance. Finally, tests will be carried out to verify the impact on the performance of the targeted functionality.


    \vspace{\onelineskip}

    \noindent
    \textbf{Key-words}: Web Applications. MVC Design Pattern. Ruby on Rails. Performance
  \end{otherlanguage*}
 \end{resumo}
