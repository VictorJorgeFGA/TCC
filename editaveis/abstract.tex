\begin{resumo}[Abstract]
  \begin{otherlanguage*}{english}
   Modern web applications typically consist of three major components: the back-end, front-end, and database. Frameworks based on design patterns such as Model-View-Controller (MVC) may face scalability and performance issues, particularly when handling intensive database usage. In a real-world scenario, the Brasil Participativo platform reached a relatively high number of users (1.4 million), revealing various weaknesses and bottlenecks in its architecture, as well as in the approach used to develop the Decidim gem, which is built on the Ruby on Rails framework.

    This work aims to describe a refactoring process for the application, focusing on performance enhancement. To achieve this, we will research strategies that best optimize Ruby on Rails applications. Subsequently, tests will be conducted to evaluate the impact of the implemented modifications.

    \vspace{\onelineskip}

    \noindent
    \textbf{Key-words}: Web Applications. MVC Design Pattern. Ruby on Rails.
  \end{otherlanguage*}
 \end{resumo}
